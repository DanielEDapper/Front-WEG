# Front-WEG 🚀

Este repositório é dedicado ao armazenamento de projetos, exercícios e avaliações desenvolvidos durante meus estudos de **Desenvolvimento Frontend** na WEG. O foco principal é o domínio de tecnologias fundamentais de interface.

## 📚 Conteúdo do Repositório

O repositório está organizado por módulos e atividades práticas:

- **Prova:** Arquivos e resoluções de avaliações técnicas recentes.
- **ProfeIgor:** Estrutura inicial de frontend seguindo as orientações do instrutor.
- **mirrorFashion:** Desenvolvimento de uma Landing Page (Atividade da Aula 7).
- **Coffee:** Exercícios práticos focados em **alinhamento e layout**.
- **CEP & CentroIdeias:** Implementações e práticas da Aula 2.
- **Music & PraticasSimples:** Projetos iniciais para fixação de conceitos básicos.

## 🛠️ Tecnologias Utilizadas

De acordo com as estatísticas do projeto, o desenvolvimento foca intensamente na estilização e estrutura:

- **CSS3 (86%):** Prática intensiva de layouts, Flexbox, Grid e design responsivo.
- **HTML5 (14%):** Estruturação semântica de páginas web.
